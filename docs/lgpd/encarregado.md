# Encarregado (art. 41 da LGPD)

Nomeação interna, versão 1.0, 2026-10-05. O encarregado é função da própria operação, não um prestador externo.

| Campo | Valor |
| --- | --- |
| Cargo | Encarregado pelo tratamento de dados pessoais |
| Quem ocupa | Administração da plataforma ISM Tecnologia. A conta de bootstrap já existente no sistema é `admin@ism.finance`. |
| Canal | encarregado@ism.finance |
| Suplente | A mesma função, pela conta de administração, até a direção designar outra pessoa por escrito. |

Pedido de titular e incidente entram por esse canal. Troca de pessoa actualiza esta tabela e a política de privacidade no mesmo commit. O acto interno de direção, se for em papel, fica fora do git; o nome do cargo e o canal ficam aqui.
